# 课程成绩重算与综测核对

交付可追溯的计算结果，明确已核验人员和待解决项。只处理用户指定的班级、学期、名单、工作表和字段。

## 先确定范围和规则

从用户、原始表和学校规则中确定学期、名单、课程范围、及格线、等级换算、挂科处理、缓考/缺考/未出分处理、权重和取整方式。原任务采用挂科记 0、学分仍计入分母；优秀 95、良好 85、中等 75、及格 65；科学文化 × 70% + 考评 × 30%。这些是任务配置示例，不能直接当作其他学校的政策。

未挂科人员只有在用户要求时沿用原加权平均分；否则逐课重算。未知规则先询问，同时完成不依赖该规则的提取与核验。不要把报表中的 0 自动认定为挂科。

## 提取与核验

- 以字符串学号为唯一人员标识，保留前导零；姓名和班级作复核。照片或手写名单中的模糊、划掉、重名记录先核对，不能猜。
- 从独立课程清单确定应有课程；逐课记录原始成绩、状态、学分以及来源文件/工作表/行号。按专业、年级、学期核查学分，课程别名经确认后统一到稳定课程 ID。系统“已得学分”只作辅助核验。
- 重修、补考、缓考补录按学号、学期、课程和考试记录匹配。先按确认的政策选择有效记录，再计算；不得把同一课程的多次考试重复计入。
- 缺失/冲突学分、身份冲突、未知等级、未确认状态只阻止受影响人员。全局名单不一致时先修正范围，避免漏人和添人。

## 计算

读取 [数据与计算协议](references/data-contract.md)，将已核验数据转换为协议中的 JSON。脚本位于本 Skill 目录下：

```bash
python3 scripts/audit_grades.py normalized.json --output audit.json
```

命令路径相对于本 Skill 目录；其他工作目录下使用脚本的绝对路径。退出码 0 表示全部通过；2 表示有阻塞或输入无效。查看报告状态和每人的 errors，不能只看文件是否生成。

科学文化成绩 = Σ(课程学分 × 计入成绩) / Σ计分课程学分。挂科记 0 时仍保留该课程学分；未出分处理按确认的配置。默认用未取整值计算综测，只在展示时四舍五入两位。脚本保留十进制计算值、分子、分母、逐课决定和规则快照。其他取整顺序需根据学校规则调整脚本或单独计算并验证，不能默默套用。

## 写回与交付

读取 [工作簿与交付检查](references/workbook-checks.md) 后写回。使用可用的表格工具，保留其他工作表、人员顺序、排名规则、公式及样式；输出副本，除非用户明确要求覆盖。不得擅自新增排名、备注或名单成员。

重开输出文件，核对指定人数、学号集合、课程完整性、总学分、公式引用以及显示值与精确值的关系。抽查至少一个挂科、一个等级成绩和一个正常成绩案例（存在时）。在聊天中简要说明完成数和待确认项；用户要求简洁表格时，将溯源留在单独审计文件。

## 数据边界

成绩数据仅在本次授权范围内处理。发布或分享此 Skill 项目时，只包含规则、代码和明确虚构的示例；不包含真实成绩、姓名学号、截图、临时文件或含个人信息的日志，也不把这些写进 Git 历史。Skill 的调用不自动授权向 GitHub 或其他服务上传成绩数据。
