# 工作簿与交付检查

## 写回前

确认目标文件、工作表、班级、学期和学号列。检查前导零、合并单元格、隐藏行列、公式、筛选及已有排名。以学号建立映射；姓名或班级不一致时先核实。照片仅作指定名单线索，不替代教务数据。用户只要求筛选不及格时，不额外重算或改写综测。

保存一份未修改的原始文件和工作表结构记录。读取成绩时区分公式与缓存值；缓存缺失或过期时通过可靠表格引擎重算或按可验证公式计算，不能把空缓存当 0。

## 写回时

只更新明确授权的单元格或生成指定格式的副本。保留未要求修改的工作表、排序、排名和样式。宏工作簿需用支持保留宏的方式处理，不静默转换。遇到工具无法保留的图表、外链或格式，先输出独立汇总并说明限制，避免破坏原工作簿。

blocked 人员不写入推测值；保留原值时明确原值未核验，交付说明列出待解决项，不能让旧值看起来像新结果。需要无备注表格时，把说明放在聊天或独立审计文件，尊重用户格式要求。

## 写回后

重新打开产物并检查：

- 目标人数、学号集合、重复记录和原始顺序。
- 未涉及工作表、公式、排名规则及工作簿结构。
- 应有课程集合、逐课学分之和、挂科学分进入分母。
- 科学文化显示两位但综测使用未提前取整的值。
- 总览、明细与审计文件一致；缓考补录只替换已核验考试记录。

产物只有在这些检查通过后才作为最终结果。未决项只阻止相关人员；用户尚未明确的政策不能由助手替学校决定。
